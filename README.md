# 短答すきまトレーナー

公認会計士試験・短答式を、机が使えないすきま時間で回すための一問一答アプリです。
監査論・財務理論・管理理論を **1つのアプリ**で切り替えて使えます。

## このリポジトリに教材は入っていません

アプリ本体だけを置いています。問題と解説は `○○-cards.json` という別ファイルにあり、
**端末の中だけ**に保存されます。購入した教材の複製をインターネット上に置かないための作りです。

> **注意**
> GitHub Pages に置いたファイルは、リポジトリが Private でも URL を知っていれば誰でも取得できます。
> `*-cards.json` は絶対にこのリポジトリに入れないでください。

## 使い方

1. 教材ファイル（kansa-cards.json / zaimu-cards.json / kanri-cards.json）を端末に保存する
2. 公開された URL を開く
3. 「教材ファイルを選ぶ」から1科目ずつ読み込む（何科目でも入ります）
4. ホーム上部のボタンで科目を切り替える

## 科目ごとのアイコンをホーム画面に置く

URL に `?s=科目名` を付けて開いてから「ホーム画面に追加」すると、その科目のアイコンと名前になります。

```
.../?s=監査論     監（濃紺）
.../?s=財務理論   財（臙脂）
.../?s=管理理論   管（深緑）
```

3つとも追加すれば、これまでどおり科目ごとのアイコンから直接開けます。中身は同じアプリです。

## 更新するとき

`index.html` を差し替えて Commit するだけです。**1回で3科目すべてに反映されます。**
学習記録も教材も消えません。

## ファイル構成

```
index.html                    アプリ本体（教材は含まない）
manifest.webmanifest          既定のホーム画面設定
manifest-kansa/zaimu/kanri    科目ごとのホーム画面設定
icon-*.png                    アイコン（科目別＋既定）
sw.js                         オフラインで開くための取り置き
.nojekyll / .gitignore
```

## 記録の保存先

学習記録はブラウザの中に、教材は IndexedDB に、いずれも科目ごとに分けて保存されます。
サーバには何も送りません。記録タブから書き出し・読み込みができます。

**ブラウザのサイトデータを消すと記録も消えます。** ときどき書き出しておくと安全です。
